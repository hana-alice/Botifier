# Face Lab

原创电子宠物的浏览器**动作设计预览**，无外部依赖、品牌素材或硬件连接。Canvas 使用 **320×240 逻辑坐标**，显示尺寸适配桌面和 375px 屏幕；高 DPI 只提高画布分辨率。HOME/TUNE 按机器人布局 `(12,190,92,40)/(216,190,92,40)` 绘制，均为位置占位，不连接设备。

从 `F:\stackchan` 启动现有 Python 的静态服务器：

```powershell
py -3.12 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/demos/face-lab/>；也可直接打开 `index.html`。

## 实际固件渲染图集

打开 [firmware.html](firmware.html) 查看开心、撒娇、委屈和提醒周期四段动画。资产从 `.tools/pet-renderer/frames` 原样复制；[渲染记录](firmware/manifest.json) 来自 `.tools/pet-renderer/manifest.json`，保留固件源码哈希与渲染验证信息。[完整静态姿态图](firmware/contact.png) 也已保留。

这些是**实际固件代码的桌面 LVGL 软件渲染片段，非 LCD 实拍**，仅含脸部，不含 HOME/TUNE 和全局警告红框。源渲染为 320×240 XRGB8888；与设备显示量化、Canvas 原创预览都不保证像素一致。四张动画按 320×240 原始尺寸显示，375px 页面无需放大或横向滚动。

页面默认遵循 `prefers-reduced-motion`：减少动态时只加载对应静态图；用户可显式播放。暂停切换到代表静态姿态，播放时切回动画片段；后台页面同样切到静态图。无 JavaScript 时显示静态图。四段动画均为 APNG；前三段 71 帧、20ms/帧，提醒周期 100 帧、20ms/帧；重复帧保留原固件的更新节奏。

主代理已在实际浏览器复审图集：1440px 双列、375px 单列，无横向溢出，四图成功加载且显示尺寸 320×240；减少动态默认静态、显式播放及暂停切回静态均通过。桌面和手机截图仅作为页面布局证据，不是机器人实拍。

## 浏览器动作设计

动作按钮可重新播放当前动作。距离全部由滑杆或按钮模拟：小于 **40cm** 时提醒抢占动作；**40..47cm** 保持提醒；达到 **48cm** 后依次放松、开心、放松、平静。自动模式在平静停留后继续编排。减少动态默认尊重系统设置，并禁用自动播放、呼吸和眨眼；距离仍即时响应。暂停不阻止用户切换动作或修改模拟距离。所有控件都可使用 Tab、Enter、Space 和滑杆方向键。

## 动作与可移植参数

`poseFor(mode, milliseconds)` 产生两眼各自的 `x/y/w/h/r/rotation/smile/lid`，无逐帧随机数。左右眼默认中心 `(106,116)/(214,114)`、尺寸 `65×76/62×72`、圆角 `27/26`；Canvas 以圆角矩形、三次贝塞尔弧和上睑裁切绘制，不需要纹理。

笑眼采用**单个不透明轮廓形变**：`smile=0..0.45` 先用 smoothstep 把实体高度压到 `min(15,h)` 的胶囊短线；`0.45..1` 再把同一短线平滑弯成圆端贝塞尔笑弧。两阶段在 0.45 处几何一致，不同时叠画实体眼和笑弧，也不使用透明度交叉淡入。wink 原有小于 15px 的闭眼高度保留；上睑裁切随压缩减弱，避免跨表情转场突然出现切口。

| 动作 | 参数及节奏 |
| --- | --- |
| `idle` 平静 | 小幅 4px 眼神偏移，移动与回看之间保留秒级停留 |
| `glance` 转向回看 | 水平 `-19/+17px`，260–560ms 转向；停留约 1.2s；第二眼跟随晚 34ms |
| `curious` 好奇 | 左眼上抬至 y103、`71×88`；右眼 `56×61`，旋转 `-0.12/+0.065rad` |
| `happy` 开心 | 单轮廓压扁后弯成 15px 宽的大幅贝塞尔笑眼，左右形变参考高 `43/40px`，搭配笑口、淡腮红和爱心 |
| `affection` 撒娇 | 左右眼形不同、笑眼比例 `0.8/0.95`；侧蹭 `+16/-12px` 后停留，粉色腮红与爱心 |
| `shy` 害羞 | 两眼向内收窄至 `45×45/43×40`，低头眼神、小笑口与明显腮红 |
| `sad` 委屈 | 反向上睑斜切、下垂眼、小弯嘴；左右 y156/y163 的蓝色小泪滴 |
| `sleepy` 困倦 | 左右高 `27/21px`，向下偏移、轻微不同角度 |
| `surprised` 惊讶 | 窄高 `52×98/49×91` 眼睛与小圆口 |
| `wink` 单眼眨 | 左眼在 560..1020ms 闭合 96%，1240ms 睁开；右眼保持展开 |
| `warning` 认真 | 上睑斜切约 25px，眼高 `62/59`，柔琥珀色；无自动眨眼 |
| `relaxed` 放松 | 宽而低的 `71×54/68×51` 眼形，轻微笑口 |

转场使用 `smoothstep(x)=x²(3−2x)`，左眼约 290ms，右眼延后 34ms、约 306ms。呼吸仅为垂直 1.6px 正弦，周期 3.9s、右眼幅度 72%；没有随机抖动。普通眨眼在 34.5s 时间表中以不等间隔出现，闭合 76ms、睁开 126ms，包含两次双眨；第二眼晚 19ms、闭合深度略小。恢复编排为放松 480ms、开心 1220ms、放松 900ms，再平静 2600ms。提示是程序状态，不代表看见或听见用户。

## 固定时间测试接口

```js
faceLab.reset();
faceLab.setMode('curious');
faceLab.sampleAt(900); // 相对当前动作起点的毫秒；同时暂停，便于截图
faceLab.getState();    // activeMode / alert / program / time / pose 等

faceLab.setDistance(30);
faceLab.sampleAt(400); // 认真提醒
faceLab.setDistance(45); // 保持提醒
faceLab.setDistance(60);
faceLab.sampleAt(1000); // 恢复中的开心
faceLab.sampleAt(4000); // 已回平静
faceLab.setPaused(false);
faceLab.setReducedMotion(true);
```

`setMode` 支持表格中的十二个名字及 `auto`；另接受 `surprise/alert/relief` 作为 `surprised/warning/relaxed` 别名。提醒期间仍允许选择动作，但不解除提醒；恢复后手动模式回到 `idle`，自动模式继续编排。`sampleAt()` 可前后定位当前动作/恢复片段；超过转场结束时，相同模式与时间得到相同几何。重置后可复现全流程。测试接口只改变浏览器模拟。

Canvas 页面是独立动作设计，固件不采用同一组数字参数。电子宠物固件已构建、部署并通过启动与测距检查，实际视觉渲染证据见上方图集；设备 LCD 观感仍需现场确认。

已执行内联 JavaScript 语法检查，以及用 Node VM 的 DOM/Canvas 替身执行真实页面脚本的 48 项状态检查，覆盖动作几何可复现、阈值边界、提醒抢占、恢复序列和减少动态。主代理已在实际浏览器复审最终 affection/happy/wink 截图：单轮廓笑眼没有此前重影，wink 正常，375px 无横向溢出。此前 1440/375px 布局和 11 项核心状态也通过浏览器检查。固件图集页面的实际浏览器视觉检查另由主代理负责。
